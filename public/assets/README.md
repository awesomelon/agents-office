# Studio artwork

`codex-studio.webp` is the application-owned office background generated for this
redesign with the built-in image-generation tool. It is not a screenshot of the app.
The chosen image was inspected, then encoded as WebP at quality 88 without changing
its 1536 × 1024 dimensions, framing or scene content. File size: 158,240 bytes.
It is bundled locally and requires no image service at runtime.

The generated result contains six workstations, not the eight requested in the
prompt. The implementation deliberately uses those six desks plus the resource
library and conversation lounge as its eight distinct role zones. Labels, observed
statuses and selection indicators are rendered separately by React.

## Original generation prompt

Use case: stylized-concept. Asset type: production background illustration for an
interactive Codex Office desktop application. Generate a premium 3D rendered
isometric miniature creative coding studio, landscape 1536x1024. Entire room is a
clean architectural cutaway diorama viewed from above at about 40 degrees, with all
eight individual workstations clearly visible and plenty of separation for
clickable UI pins added later. Exactly EIGHT empty individual desks arranged as two
clear columns, four rows, each has one slim dark monitor, keyboard and a small chair;
no people, no robots. Warm light oak tables, pale sand floor, cream rear wall with
tall windows, ink navy frames, muted sage green desk mats/chairs and small plants,
a single terracotta lounge chair in far corner, tidy shelf/books in back. Front
walls absent. Sophisticated physical materials, soft ambient occlusion, realistic
soft long afternoon shadows, subtle rounded edges, tactile architectural model
quality, quietly playful but refined, no cartoon outlines, no tiny clutter. On
solid deep ink teal background #14262b with very soft ground shadow. Room fills 88%
width and 82% height, centered, front edge fits completely. Desks arranged in two
columns aligned diagonally with room axes and four rows down the room, eight
clearly separated workstations. Leave enough visual space between desks for eight
small numbered pins. No text, labels, logos, watermark, UI, people or baked-in
activity glows. Output polished, crisp, high resolution. This is the actual
application illustration, not a screenshot mockup.
